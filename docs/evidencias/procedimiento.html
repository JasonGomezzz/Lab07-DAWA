Evidencias del procedimiento.

Laboratorio 07 · Seguridad en aplicaciones con JWT. Salidas reales capturadas en la máquina local el 03/10/2026 (Node 22.18, MongoDB 8.0).

Iniciar el servidor

Comando: npm run dev (primer arranque con siembra de roles y arranque con nodemon).

01-npm-run-dev.txt
# Evidencia del procedimiento: iniciar el servidor
# Fecha: 2026-10-03 09:21 · Node v22.18.0 · MongoDB 8.0 local (brew services)

# Primer arranque, con auth_db sin roles: seedRoles los crea.
$ node src/server.js
Mongo connected
Seeded roles: user, admin
Servidor corriendo en el puerto 3000

# Arranque en modo desarrollo (los roles ya existen, seedRoles no repite la inserción):
$ npm run dev
